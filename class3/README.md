# 完整小孔检测

图像灰度化、高斯滤波后反向二值化，使用闭运算及 8 邻域连通域统计，再通过边界、面积、宽高比和填充率筛选小孔。`binary.png` 是二值化结果，`selected.png` 是筛选出的连通域，`result.png` 是编号结果。

在 VS Code 中打开 `class3/main.cpp`，选择 `Current project (MSVC x64)` 并按 F5。在图片窗口按任意键关闭窗口。

也可在本目录运行 `build.bat`，然后运行 `build\app.exe`；默认读取 `part.jpg`，也可通过命令行传入其他图片路径。

阈值 95、面积范围 400～12000 像素以及形状条件针对示例图设置。其他光照、尺寸或粘连情况下，需要重新调整参数；边界判定针对阈值分割后的连通域。
